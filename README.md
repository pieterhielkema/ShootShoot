# ShootShoot
Goal of the game is to hit your friends with balls.

### Controls
Shoot: Click
Walk: W / Arrow Up (direction of mouse)
Mobile: hold finger to walk towards it, 🎾 button to shoot

### Run
```
npm install
npm start
```
